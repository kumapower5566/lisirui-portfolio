# lisirui — UI Designer Portfolio

A dark, motion-rich portfolio landing page for lisirui, a UI/UX designer.

## Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React
- @react-three/fiber + @react-three/drei (3D hero model)

## Highlights

- Full-viewport hero with an interactive 3D character (GLB) that tilts toward the cursor and gently sways.
- Scroll-driven marquee showcase row.
- Character-by-character scroll reveal for the about paragraph.
- Sticky card-stacking projects section.
- Dark `#0C0C0C` theme with a violet-orange gradient accent, Kanit typeface, and bilingual (English headings / Chinese body) copy.

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
